### 二、docker-compose.yml（核心）

必须包含以下四个服务，容器间通过网络 `learn-with-ai-network` 互联：

1. **postgres**：使用 `pgvector/pgvector:pg16` 镜像
   - 环境变量：`POSTGRES_USER=learn`, `POSTGRES_PASSWORD=learn123`, `POSTGRES_DB=learn`
   - 端口映射：`5432:5432`
   - 挂载卷：`postgres_data:/var/lib/postgresql/data`
   - 健康检查：`pg_isready -U learn`

2. **redis**：使用 `redis:7-alpine` 镜像（暂用于后续缓存，先占位）
   - 端口映射：`6379:6379`

3. **backend**：构建 `./backend/Dockerfile`
   - 端口映射：`8000:8000`
   - 环境变量从 `.env` 读取
   - 依赖 postgres（等待健康检查通过后再启动）
   - 容器内工作目录：`/app`
   - 启动命令：`uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload`

4. **frontend**：构建 `./frontend/Dockerfile`
   - 端口映射：`5173:5173`
   - 启动命令：`npm run dev -- --host 0.0.0.0`
   - 依赖 backend（仅逻辑依赖，不强制等待）
