## 二、编辑模式交互

### 2.1 节点选择与关系编辑

| 操作 | 系统行为 |
|------|----------|
| 单击节点 A | 节点 A 进入选中状态（高亮边框+发光效果） |
| 再次单击节点 A | 取消选中状态 |
| A 已选中，单击节点 B | 弹出「编辑关系」浮窗（浮窗定位在 A-B 连线的中间位置附近） |

**编辑关系浮窗**：

```
┌─────────────────────────────────────────────┐
│  编辑关系                                   │
│  ─────────────────────────────────────────  │
│  源节点：自我意识                           │
│  目标节点：自我概念                         │
│  ─────────────────────────────────────────  │
│  关系类型：[contains ▼]                    │
│  描述：    [自我意识包含自我概念  ]         │
│  ─────────────────────────────────────────  │
│  [删除]  (仅已有关系时可用)                 │
│  [取消]                    [保存]          │
└─────────────────────────────────────────────┘
```

**浮窗行为**：

| 用户操作 | 系统行为 |
|----------|----------|
| 选择关系类型（下拉） | 更新浮窗中的类型字段 |
| 修改描述文本 | 更新浮窗中的描述字段 |
| 点击「保存」 | 创建（无关系时）或更新（已有关系时）关系，关闭浮窗 |
| 点击「取消」 | 关闭浮窗，不保存任何更改 |
| 点击「删除」 | 删除关系，关闭浮窗（仅已有关系时可用） |
| 浮窗打开时，点击浮窗外部 | 不关闭浮窗（防止误触） |

### 2.2 连线编辑

| 操作 | 系统行为 |
|------|----------|
| 单击连线 | 弹出「编辑连线」浮窗（浮窗定位在连线中间位置） |

**编辑连线浮窗**（与关系浮窗相同，但标题为「编辑连线」）：

```
┌─────────────────────────────────────────────┐
│  编辑连线                                   │
│  ─────────────────────────────────────────  │
│  源节点：自我意识                           │
│  目标节点：自我概念                         │
│  ─────────────────────────────────────────  │
│  关系类型：[contains ▼]                    │
│  描述：    [自我意识包含自我概念  ]         │
│  ─────────────────────────────────────────  │
│  [删除]                                    │
│  [取消]                    [保存]          │
└─────────────────────────────────────────────┘
```

**连线编辑后**：删除或保存操作后，浮窗关闭，画布上的边立即更新。

### 2.3 取消选中

| 操作 | 系统行为 |
|------|----------|
| 点击画布空白处 | 取消所有选中节点 |
| 切换到浏览模式 | 取消所有选中节点 |
| 按 ESC 键 | 取消所有选中节点 + 关闭浮窗（如有） |

## 三、撤销机制

### 3.1 撤销栈

每次执行**持久性操作**（创建/更新/删除关系）前，将当前关系状态压入撤销栈：

```typescript
interface HistoryEntry {
  type: 'create' | 'update' | 'delete'
  relation: {
    source_entity_id: string
    target_entity_id: string
    relation_type: string
    description: string
  } | null  // null 表示原本无关系
  timestamp: number
}
```

### 3.2 撤销行为

| 操作 | 系统行为 |
|------|----------|
| Ctrl+Z | 读取栈顶条目，恢复到操作前状态，弹出栈顶 |
| 栈为空 | Ctrl+Z 无效果（静默或提示） |

### 3.3 撤销范围

**撤销栈仅记录编辑模式下的操作**（创建/更新/删除关系），不影响：
- 图谱展开（F1）操作（由 `graphStore.expandedIds` 单独管理）
- 路径查找（F2）操作（仅高亮，不修改数据）
