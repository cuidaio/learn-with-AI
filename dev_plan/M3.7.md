## 二、滚动修复（立即生效）

### 2.1 问题原因

`EntitiesView.vue` 中实体列表容器的底部没有预留足够空间，导致最后一个实体被底部操作栏或父容器截断。

### 2.2 修复方案

在实体列表底部增加一个 **不可见占位元素**，高度等于一个实体条目高度（约 60px），确保最后一个实体完整可见。

```vue
<!-- 在实体列表末尾添加 -->
<div class="placeholder-item" style="height: 60px; flex-shrink: 0;"></div>
```

**或者更干净的方案**：调整容器样式，增加底部 padding。

```css
.entity-list {
  padding-bottom: 80px;  /* 确保最后一项不被底部遮挡 */
  overflow-y: auto;
  max-height: calc(100vh - 200px);  /* 根据实际布局调整 */
}
```

**推荐**：同时使用两种方案——容器 padding + 末尾占位元素，双重保障。

## 四、导出功能

### 4.1 导出格式

支持导出为 **Markdown** 和 **JSON** 两种格式。

**Markdown 格式**（适合外部整理、打印）：

```markdown
# 实体列表 - 青少年个性发展
导出时间：2026-07-18 14:30
实体数量：23

## 概念 (12)

### 自我意识
- 类型：concept
- 描述：个体对自己身心状况及与他人关系的认识
- 上下文：自我意识是指个体对自己身心状况及与他人关系的认识...
- 状态：已确认
- 来源：LLM

### 自我概念
...

## 理论家 (4)

### 皮亚杰
...
```

**JSON 格式**（适合备份、程序导入）：

```json
{
  "export_time": "2026-07-18T14:30:00",
  "document_id": "xxx",
  "entities": [
    {
      "name": "自我意识",
      "type": "concept",
      "description": "...",
      "introduction_context": "...",
      "filter_action": "keep",
      "source": "llm"
    }
  ]
}
```

### 4.2 导出选项

点击「📥 导出」后，弹出导出对话框：

## 五、滚动修复 + 批量操作 — 接口/API

### 5.1 实体查询 API 增强

```python
GET /api/entities
Parameters:
  - document_id: str (required)
  - filter_action: str (optional: 'keep' | 'review' | 'discard' | 'all')
  - entity_type: str (optional: 'concept' | 'theorist' | 'theory' | 'method' | 'fact')
  - search: str (optional, 模糊搜索 name/description)
  - sort_by: str (optional: 'name_asc' | 'name_desc' | 'created_asc' | 'created_desc')
  - limit: int (optional, default 100)
  - offset: int (optional, default 0)

Response:
{
  "entities": [...],
  "total": 23,
  "filters": {
    "filter_action": "keep",
    "entity_type": null,
    "search": null,
    "sort_by": "name_asc"
  }
}
```

### 5.2 实体编辑 API

```python
PUT /api/entities/{id}
Request:
{
  "name": "自我意识（更新后）",
  "type": "concept",
  "description": "更新后的描述",
  "introduction_context": "更新后的上下文",
  "filter_action": "keep"  # keep | review | discard
}

Response:
{
  "id": "xxx",
  "name": "自我意识（更新后）",
  "type": "concept",
  "updated_at": "2026-07-18T14:35:00"
}
```

### 5.3 实体导出 API

```python
GET /api/entities/export
Parameters:
  - document_id: str (required)
  - filter_action: str (optional)
  - format: str (optional, 'markdown' | 'json', default 'markdown')

Response:
  - Markdown: text/plain
  - JSON: application/json
```
