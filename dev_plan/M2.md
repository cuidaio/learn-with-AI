## 二、Prompt设计的科学审视

你质疑我的Prompt写法是否科学。我查阅了RAG系统提示设计的前沿文献，核心发现如下：

### 2.1 RAG Prompt的黄金法则

**法则一：相关性排序——最相关的内容放前面**

模型存在“注意力不足症”——对Prompt末尾内容的关注度会衰减。因此，**最相关的参考资料必须放在最前面**，而不是按文档原始顺序排列。

**法则二：格式清晰——用明确标记分隔不同来源**

使用 `[1]`、`[2]` 等编号标记每个参考来源，并在回答中引用这些编号。这既帮助模型组织信息，也方便用户溯源。

**法则三：上下文与问题严格分离**

用明确的标记（如 `### 参考资料` 和 `### 问题`）将检索到的上下文和用户问题分开。模型需要清楚地区分“这是我要依据的材料”和“这是我要回答的问题”。

**法则四：设置“不知道”的边界**

明确告诉模型：如果参考资料中没有相关信息，必须说“基于提供的资料，我无法回答这个问题”。这是防止幻觉的第一道防线。

### 2.2 我之前的Prompt有什么问题

**我之前的写法：**

```
[系统] 你是一位考研心理学辅导老师。请根据以下教材内容回答学生的问题。

【教材内容】
{section_blocks_content}

【学生问题】
{question}

【要求】
1. 只根据上述教材内容回答，不要使用外部知识
...
```

**问题诊断：**

| 问题 | 说明 |
|------|------|
| **参考资料未编号** | 没有用 `[1]`、`[2]` 标记不同来源，模型无法精确引用 |
| **多个章节块混杂** | 如果有多个L1块，内容堆在一起，模型难以区分来源 |
| **“教材内容”位置靠后** | 参考资料放在问题之后，模型注意力可能偏向问题而非资料 |
| **未强制要求引用编号** | 虽然要求“标注引用来源”，但没有明确要求使用编号格式 |
| **系统角色过于宽泛** | “考研心理学辅导老师”是角色设定，但没有约束回答的格式和结构 |

### 2.3 科学Prompt的结构（RAG专用）

根据RAG提示工程最佳实践，一个科学的RAG Prompt应遵循以下结构：

```
[系统] 定义角色 + 定义任务 + 定义边界（何时说“不知道”）+ 定义输出格式

### 参考资料（按相关性排序）
[1] 来源A：{content}
[2] 来源B：{content}
[3] 来源C：{content}

### 问题
{user_question}

### 回答要求
- 只基于上述参考资料回答
- 在回答中引用来源编号，如
- 如果参考资料不足，明确说明
```

**关键原则**：参考资料放在问题**之前**，且按相关性**降序排列**。

### 一、核心功能

用户输入问题 → 向量检索命中 `sub_chunks` → 聚合为 `section_blocks` 上下文 → **按相关性排序组装Prompt** → LLM生成回答 → 返回带编号引用的答案

---

### 二、新增接口

#### `POST /api/ask`

**请求体**：

```json
{
  "document_id": "uuid",
  "question": "自我意识在青春期有什么特点？",
  "top_k": 5
}
```

**`top_k`**：检索命中的子块数量，默认5。

**处理流程**：

1. 将 `question` 转换为向量（调用 Embedding API）
2. 在 `sub_chunks` 表中检索与问题向量最相似的 `top_k` 个子块
   - SQL: `SELECT * FROM sub_chunks WHERE document_id = ? ORDER BY embedding <=> ? LIMIT ?`
   - `<=>` 是 pgvector 的余弦距离算子
3. 获取这些子块所属的 `section_block_id`（去重），加载完整的 `section_blocks` 内容
4. **按相关性排序**：将命中的子块按相似度分数从高到低排列，对应的章节块也按此顺序组织
5. 构造 Prompt（见下方模板）
6. 调用 LLM API（ChatCompletion），`temperature=0.1`
7. 返回答案 + 引用来源列表

---

### 三、Prompt模板（科学版本）

**System Prompt：**

```
你是一位考研辅导老师，擅长根据教材内容回答学生的专业问题。

你的任务：
1. 仅基于下方【参考资料】回答学生的问题
2. 如果参考资料中没有相关信息，明确回答“教材中未涉及该内容”
3. 回答应条理清晰、重点突出，适合考研复习使用
4. 在回答中引用来源编号，格式为【来源编号】

输出格式：
- 直接输出回答内容
- 不要输出“根据参考资料”这类冗余表述
- 引用放在句末或段末
```

**User Prompt 结构（参考资料在前，问题在后）：**

```
### 参考资料（按相关性从高到低排列）

[1] 来源：{section_title_1}
{section_content_1}

[2] 来源：{section_title_2}
{section_content_2}

[3] 来源：{section_title_3}
{section_content_3}

### 问题
{question}

### 回答
```

**设计依据：**
- 参考资料放在问题之前，让模型先建立知识背景
- 按相关性降序排列，最相关内容最先被模型关注
- 每个来源有独立编号，便于模型引用和用户溯源
- 明确的“不知道”边界，防止幻觉
- temperature=0.1，确保回答稳定、可重复
