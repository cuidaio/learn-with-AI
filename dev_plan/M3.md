### 1.1 三栏布局

```
+------------------+----------------------------+-----------------------------------+
|  左栏：文档区     |   中栏：呈现区             |   右栏：任务区                    |
|   (~20%)         |   (~55%)                  |   (~25%)                         |
+------------------+----------------------------+-----------------------------------+
|  📁 我的资料库    |  [内容标题 + 类型标签]     |  [＋ 创建任务]   ← 顶部固定       |
|  [+ 上传] [+ 新建]|  ────────────────────────  |  ───────────────────────────────  |
|  ──────────────── │  内容动态渲染区域          |  💬 AI对话        ← 常驻快捷区    |
|  📂 发展心理学    |                           |  📋 实体一览                     |
|    📄 第一章      |  支持的内容类型：          |  ─── 任务卡片堆叠 ───            |
|    📄 第二章      |  - document（原文阅读）    |  ┌──────────────────────────┐    |
|  📂 教育心理学    |  - chat（AI对话）         |  │ 📝 自我意识训练题  ✅    │    |
|    📄 第三章      |  - entities（实体一览）    |  │ 2026-07-15 14:30        │    |
|                   |  - questions（题目集）     |  └──────────────────────────┘    |
|                   |  - knowledge_graph（图谱）  |  ┌──────────────────────────┐    |
|                   |                           |  │ 📊 知识图谱         ✅    │    |
|                   |                           |  │ 2026-07-15 14:20        │    |
|                   |                           |  └──────────────────────────┘    |
+------------------+----------------------------+-----------------------------------+
```

### 1.2 设计原则

1. **固定元素在上，动态内容在下**：创建任务按钮、常驻快捷区固定在右栏顶部，任务卡片在下方堆叠滚动
2. **用户控制权**：中栏显示什么由用户点击卡片决定，系统不自动跳转
3. **任务成果是累积资产**：所有已完成任务以卡片形式保留，可反复访问
4. **中栏是统一渲染容器**：根据内容类型动态切换渲染模板
5. **左栏是基础设施**：管理文档和文件夹，是一切操作的起点

## 三、中栏：呈现区

### 3.1 设计原则

- 中栏是**动态内容容器**，根据用户点击的卡片类型渲染不同内容
- 内容类型由任务结果的 `content_type` 字段决定
- 中栏顶部显示当前内容的标题和类型标签

### 3.2 支持的内容类型（M3）

| 类型 | 渲染组件 | 说明 | 触发方式 |
|------|----------|------|----------|
| `document` | `DocumentReader` | 显示文档原文，实体名词高亮 | 点击左栏文档 / 默认卡片 |
| `chat` | `ChatView` | AI对话界面 | 点击右栏「AI对话」快捷区 |
| `entities` | `EntitiesView` | 实体列表 | 点击右栏「实体一览」快捷区 |
| `questions` | `QuestionViewer` | 题目列表，可作答 | 点击B类任务卡片 |
| `knowledge_graph` | `GraphViewer` | 实体-关系图谱 | 点击B类任务卡片 |

### 3.3 内容加载流程

```
用户点击卡片（或选中文档/快捷区）
    ↓
获取内容数据（API调用或本地状态）
    ↓
根据 content_type 选择渲染组件
    ↓
中栏切换到对应内容
    ↓
顶部显示：类型标签 + 标题 + 时间
```

### 3.4 实体高亮（DocumentReader）

在原文中：
1. 获取当前文档的所有实体名称列表
2. 在原文中匹配实体名称
3. 用 `<mark class="entity-highlight">` 包裹
4. 悬停显示实体类型（concept/theorist/theory/method/fact）

### 3.5 API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/documents/{id}/with-highlights` | GET | 获取文档原文 + 实体高亮标记 |
| `/api/tasks/{id}/result` | GET | 获取任务结果 |
| `/api/documents/{id}/entities` | GET | 获取文档实体列表 |
| `/api/documents/{id}/chat-context` | GET | 获取对话上下文（文档摘要） |

```
┌─────────────────────────────────────┐
```

**状态与样式**：

| 状态 | 标签 | 样式 | 可点击 |
|------|------|------|--------|
| pending | 排队中... | 灰色 | ❌ |
| running | 运行中... | 黄色 + 进度条 | ❌ |
| completed | ✅ 已完成 | 绿色 | ✅ |
| failed | ❌ 失败 | 红色 | 点击重试 |

**点击行为**：
- 已完成 → 中栏切换到对应内容
- 运行中 → 不可点击（显示加载状态）
- 失败 → 弹出“是否重试？”

**顺序规则**：
- 按创建时间倒序排列（最新在上）
- 运行中卡片保持在顶部（覆盖时间顺序）
- 支持滚动查看所有卡片

**删除**：
- 悬停显示 ✕ 删除按钮
- 点击后确认删除
- 仅删除卡片，不删除底层数据（如需彻底删除，需单独操作）

### 4.5 默认卡片

- 点击后中栏显示文档原文（带实体高亮）
- 该卡片永久存在，不可删除
- 即使文档被删除，卡片保留为灰色状态（显示“文档已删除”）

## 五、任务执行流程

### 5.1 出题任务

1. 用户点击「＋ 创建任务」→ 浮窗出现（**全新实现**）
2. 选择「出题」，配置参数（场景、实体、题型）
3. 点击「确认创建」→ 浮窗关闭，任务创建
4. 状态：pending → running（卡片显示进度）
5. 后台并行出题（max_workers=3）
6. 完成后 → completed，卡片自动更新
7. 用户点击卡片 → 中栏显示题目列表

### 5.2 知识图谱任务

1. 用户点击「＋ 创建任务」→ 浮窗出现
2. 选择「知识图谱」，无需额外配置
3. 点击「确认创建」→ 浮窗关闭，任务创建
4. 后台提取实体和关系
5. 完成后 → completed，卡片自动更新
6. 用户点击卡片 → 中栏显示图谱可视化

### 5.3 任务结果格式

所有任务结果统一格式：

```json
{
  "content_type": "questions",  // 决定中栏渲染组件
  "title": "自我意识训练题",
  "data": {
    // 根据 content_type 不同
    // questions: { questions: [...], metadata: {...} }
    // knowledge_graph: { entities: [...], relations: [...] }
  }
}
```

## 六、learning_events 埋点

所有用户操作必须记录，为 M4/M5 铺垫：

| 事件类型 | 触发时机 | 记录字段 |
|----------|----------|----------|
| `document_selected` | 点击选中左栏文档 | document_id, folder_id |
| `document_uploaded` | 上传新文档 | document_id, title |
| `folder_created` | 新建文件夹 | folder_id, parent_id |
| `task_created` | 创建任务 | task_id, task_type, params |
| `task_card_clicked` | 点击卡片切换中栏 | task_id, previous_content_type |
| `quick_action_clicked` | 点击快捷区 | action_type: 'chat'/'entities' |
| `question_answered` | 在题目中作答 | question_id, correct/incorrect |
| `entity_viewed` | 查看实体列表 | document_id, entity_count |

```sql
CREATE TABLE learning_events (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID DEFAULT 'local_user',
    document_id UUID REFERENCES documents(id),
    event_type VARCHAR(30) NOT NULL,
    entity_id UUID,
    sub_chunk_id UUID,
    question_id UUID,
    context JSONB,
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_learning_events_document ON learning_events(document_id);
CREATE INDEX idx_learning_events_type ON learning_events(event_type);
```
