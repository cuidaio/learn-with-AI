## 一、新增功能

### 1.1 交互流程

1. 用户在配置面板中填写 Base URL 和 API Key
2. 点击「获取模型」按钮
3. 后端调用该平台的 `GET /v1/models` 接口
4. 返回模型列表，前端以**浮动下拉菜单**展示
5. 用户点击选择模型，自动填入「模型」输入框

### 1.2 约束条件

| 条件 | 行为 |
|------|------|
| Base URL 为空 | 「获取模型」按钮禁用，hover 提示「请先填写 Base URL」 |
| API Key 为空 | 「获取模型」按钮禁用，hover 提示「请先填写 API Key」 |
| 获取中 | 按钮显示旋转动画，禁用点击 |
| 获取失败 | 显示错误提示（如「API Key 无效」「连接失败」「平台不支持」） |
| 平台不支持 `/v1/models` | 返回友好提示「该平台不支持模型列表查询，请手动输入」 |

### 1.3 浮动下拉菜单设计

- 绝对定位浮于输入框下方，**不占据面板内部空间**
- 面板高度固定，不会忽大忽小
- 最大高度 200px，超出滚动
- 点击选项后自动填入输入框并关闭下拉
- 点击面板外部或按 ESC 键关闭下拉
- 重新点击「获取模型」刷新列表并重新打开下拉

## 二、后端接口

### 2.1 新增接口

```
GET /api/config/models
```

**请求参数（Query）**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | string | ✅ | `embedding` 或 `llm` |
| `base_url` | string | ✅ | API Base URL |
| `api_key` | string | ✅ | API Key |

**响应（成功）**：

```json
{
  "models": [
    "deepseek-chat",
    "deepseek-reasoner",
    "deepseek-v3"
  ]
}
```

**响应（失败）**：

```json
{
  "error": "API Key 无效，请检查后重试"
}
```

### 2.2 错误类型

| 错误 | 返回信息 |
|------|----------|
| API Key 无效 | `{"error": "API Key 无效，请检查后重试"}` |
| Base URL 错误 | `{"error": "无法连接到服务器，请检查 Base URL"}` |
| 平台不支持 `/v1/models` | `{"error": "该平台不支持模型列表查询，请手动输入"}` |
| 网络超时 | `{"error": "请求超时，请检查网络连接"}` |

### 2.3 实现逻辑

```python
@router.get("/models")
async def get_models(
    type: str = Query(...),
    base_url: str = Query(...),
    api_key: str = Query(...),
):
    # 1. 用提供的参数创建 OpenAI 客户端
    client = OpenAI(base_url=base_url, api_key=api_key)
    
    # 2. 调用 /v1/models
    try:
        response = await client.models.list()
        models = [m.id for m in response.data]
        return {"models": models}
    except AuthenticationError:
        raise HTTPException(400, "API Key 无效，请检查后重试")
    except APIConnectionError:
        raise HTTPException(400, "无法连接到服务器，请检查 Base URL")
    except Exception as e:
        raise HTTPException(400, f"获取模型列表失败: {str(e)}")
```

### 3.2 状态管理（ConfigStore）

```typescript
// stores/useConfigStore.ts
async function fetchModels(type: string, base_url: string, api_key: string) {
  const params = new URLSearchParams({ type, base_url, api_key })
  const res = await fetch(`/api/config/models?${params}`)
  if (!res.ok) {
    const error = await res.json()
    throw new Error(error.error || '获取模型列表失败')
  }
  return await res.json()
}
```

### 3.3 条件禁用逻辑

```typescript
const canFetchModels = computed(() => {
  return localConfig.value.base_url.trim() !== '' && 
         localConfig.value.api_key.trim() !== ''
})
```
