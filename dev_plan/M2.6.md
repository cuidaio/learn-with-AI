### 一、核心改动

**1. 新增流式响应接口（保留原有接口兼容）**

新增 `POST /api/ask/stream`，返回 `text/event-stream`：

```
data: {"type": "start", "timestamp": "..."}
data: {"type": "token", "content": "青春期"}
data: {"type": "token", "content": "是"}
data: {"type": "token", "content": "自我意识"}
...
data: {"type": "done", "sources": [...]}
```

**前端改动**：
- 在 `ChatArea.vue` 中，检测到 `document_ids` 后，调用 `/api/ask/stream` 而非 `/api/ask`
- 使用 `ReadableStream` 读取响应，逐 token 追加到 AI 消息中
- `done` 事件到达时，填充 `sources` 列表

**2. 增强性能日志**

在 `rag_engine.py` 的 `rag_ask()` 函数中，增加以下计时点：

```
- ask_start (整个请求开始)
- embed_start / embed_end (问题向量化)
- search_start / search_end (向量检索)
- context_start / context_end (上下文组装)
- llm_start / llm_end (LLM 生成)
- ask_end (整个请求结束)
```

使用 `logging.info()` 输出每个阶段的耗时（秒，保留3位小数）。

**3. 可选：加入简单缓存（先不做，视后续反馈决定）**
