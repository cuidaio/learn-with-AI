### 二、信号融合引擎（`l1_boundary_detector.py` 重写）

#### 2.1 `detect_boundaries(text: str) -> List[BoundaryDecision]`

**输入**：`cleaned_text`（预处理后的文本）

**输出**：`List[BoundaryDecision]`，每个决策包含：

```python
@dataclass
class BoundaryDecision:
    position: int
    final_confidence: float  # 0-1，综合置信度
    is_boundary: bool  # True 表示该位置被采纳为 L1 边界
    source: str  # "structural" | "vocabulary" | "continuity" | "combined" | "forced"
    structural_confidence: float
    vocabulary_confidence: float
    continuity_confidence: float
    metadata: dict
```

**处理流程**：

```
1. 获取所有候选边界及其置信度：
   a. 结构信号候选: extract_structure_signals() → 每个位置有 confidence
   b. 词汇变化候选: detect_vocabulary_shifts() → 每个位置有 confidence
   c. 连续性下降候选: detect_continuity_drops() → 每个位置有 confidence

2. 对每个候选位置，融合三种信号：
   final_confidence = max(
       structural_confidence,
       vocabulary_confidence * 0.6,  # 词汇检测作为辅助
       continuity_confidence * 0.4   # 连续性检测作为更辅助
   )
   
   # 特殊规则：当两个以上信号在同一位置附近（±50字符）时，置信度叠加
   # 叠加公式：combined = 1 - (1-c1)*(1-c2)

3. 决策采纳（层级规则）：
   a. 如果 structural_confidence >= 0.7 → 采纳为边界（不询问其他信号）
   b. 如果 structural_confidence >= 0.4 且 (vocabulary_confidence >= 0.4 或 continuity_confidence >= 0.4) → 采纳
   c. 如果 structural_confidence < 0.4 且 vocabulary_confidence >= 0.5 → 采纳
   d. 如果以上均不满足，但长度约束强制需要边界 → 采纳（source="forced", final_confidence=0.3）

4. 合并位置相近的边界（距离 < 100 字符时，保留 final_confidence 更高的）

5. 应用长度约束（与 M1.2 相同）：保证块在 500-3000 字符范围内
```

#### 2.2 结构信号置信度的细化计算

**不再使用全局 `is_structure_reliable`，改为逐位置评估**：

```python
def compute_structural_confidence(signal: StructureSignal, all_signals: List[StructureSignal], position: int) -> float:
    """
    计算该位置结构信号的置信度，考虑以下因素：
    1. 信号类型权重: Markdown标题(0.9) > 中文章节号(0.85) > 数字序号(0.6) > 其他(0.3)
    2. 信号密度: 该位置前后是否有足够多的同类信号（密度越高，置信度越高）
    3. 层级一致性: 该位置的层级是否与相邻信号层级一致（一致性高，置信度高）
    """
    # 信号类型基础分
    base_score = {
        "markdown_heading": 0.9,
        "chinese_chapter": 0.85,
        "chinese_ordinal": 0.6,
        "numeric_ordinal": 0.6,
        "other": 0.3
    }.get(signal.signal_type, 0.3)
    
    # 密度因子：检查前后各 5 个信号，计算同类信号的比例
    # 密度越高，置信度越高
    
    # 层级一致性因子：检查相邻信号的 level 是否一致
    # 一致则置信度高，不一致则置信度降低
    
    return final_score  # 0-1
```
