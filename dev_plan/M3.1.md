## 一、答题交互

### 1.1 当前状态

`QuestionViewer` 只展示题目和答案，用户点击「显示答案」展开答案，无法作答。

### 1.2 目标状态

用户在题目视图中可直接作答，提交后获得即时反馈（对/错 + 正确答案 + 解析）。

### 1.3 功能设计

**交互流程**：

```
用户看到题目
    ↓
选择题 → 点击选项（单选）/ 勾选多个选项（多选）
填空题 → 输入文本
简答题/论述题 → 输入文本
    ↓
点击「提交答案」
    ↓
前端判断（选择题直接匹配，填空/简答调用 LLM 辅助判断）
    ↓
显示反馈：
    - ✅ 正确 / ❌ 错误
    - 正确答案（如果错误）
    - 解析
    - 若错误，显示「再做一次」按钮（重置作答状态）
```

### 1.4 UI 设计

**单选题**：
```
┌─────────────────────────────────────────────────────────────┐
│  1. 青春期自我意识发展的第一个飞跃期在哪个年龄段？        │
│                                                           │
│  ○ A. 1-3岁                                              │
│  ○ B. 6-7岁                                              │
│  ● C. 11-12岁   ← 用户选择                               │
│  ○ D. 15-16岁                                            │
│                                                           │
│  [提交答案]                                               │
│                                                           │
│  ─── 反馈 ───                                            │
│  ✅ 正确！                                                │
│  解析：青春期是自我意识发展的第二个飞跃期...              │
└─────────────────────────────────────────────────────────────┘
```

**多选题**：
```
│  □ A. 自我意识                                            │
│  ☑ B. 自我概念   ← 用户选择                               │
│  ☑ C. 自我评价   ← 用户选择                               │
│  □ D. 自我控制                                            │
```

**填空题**：
```
│  青春期是自我意识发展的第____个飞跃期。                    │
│  [  二  ]  ← 输入框                                      │
│  [提交答案]                                               │
```

**简答题/论述题**：
```
│  请简述青春期自我意识高涨的表现。                         │
│  ┌─────────────────────────────────────────────────────┐ │
│  │  青春期自我意识高涨表现为...                       │ │
│  │  （用户输入区域，多行文本框）                      │ │
│  └─────────────────────────────────────────────────────┘ │
│  [提交答案]                                               │
```

### 1.5 答案判断逻辑

| 题型 | 判断方式 | 说明 |
|------|----------|------|
| 单选 | 精确匹配 | 用户选的选项 === 正确答案 |
| 多选 | 集合相等 | 用户选的选项集合 === 正确答案集合 |
| 填空 | 文本匹配 | 去除空格、大小写后比较（后续可升级为语义匹配） |
| 简答/论述 | LLM 辅助 | 调用 LLM 判断答案是否覆盖关键点（M4 实现，M3.1 先做文本相似度 + 关键词匹配） |

### 1.6 数据记录

每次答题提交，记录 `learning_events`：
```json
{
  "event_type": "question_answered",
  "question_id": "uuid",
  "context": {
    "question_type": "choice",
    "user_answer": "A",
    "is_correct": true,
    "time_spent_ms": 5000
  }
}
```

## 二、文档树拖拽管理

### 2.1 当前状态

文档树只支持点击选中，无拖拽、无右键菜单。

### 2.2 目标状态

- **拖拽排序**：同一文件夹内拖拽调整顺序
- **拖拽移动**：拖拽到不同文件夹（视觉反馈 + 确认）
- **右键菜单**：重命名、删除、移动到...

### 2.3 交互设计

**拖拽排序**：
- 长按或拖拽手柄（⋮）开始拖拽
- 拖拽过程中显示插入线（蓝色指示线）
- 释放完成排序

**拖拽移动**：
- 拖拽到文件夹名称上停留 0.5 秒 → 文件夹展开
- 释放 → 文档移动到该文件夹
- 移动确认弹窗（可选，可配置）

**右键菜单**：
```
┌─────────────┐
│ ✏️ 重命名    │
│ 🗑️ 删除      │
│ 📂 移动到... │
└─────────────┘
```

### 2.4 API 支持

```sql
-- 文档排序
PUT /api/documents/{id}/position
{"position": 3}

-- 文档移动
PUT /api/documents/{id}/folder
{"folder_id": "new_folder_id"}
```

## 三、文件上传增强

### 3.1 当前状态

仅支持文本粘贴上传，标题手动输入。

### 3.2 目标状态

- **拖放上传**：拖拽文件到左栏或上传区域
- **浏览选择**：点击上传按钮 → 选择文件
- **自动命名**：基于文件名自动生成标题
- **重名处理**：检测重名，自动添加后缀（如“第一章 (2)”）并提供确认提示

### 3.3 交互设计

**拖放上传**：
```
┌──────────────────────────────────┐
│  📤 拖放文件到此处               │
│  或点击选择文件                  │
│  支持 .txt .md .pdf .docx       │
└──────────────────────────────────┘
```

**重名处理**：
```
┌─────────────────────────────────────────────┐
│  ⚠️ 文件 "发展心理学第一章" 已存在          │
│                                             │
│  ○ 自动重命名 → "发展心理学第一章 (2)"      │
│  ● 覆盖现有文件                            │
│  ○ 取消上传                                │
│                                             │
│  [确认] [取消]                             │
└─────────────────────────────────────────────┘
```

### 3.4 API 支持

```python
# 上传文档时自动检测重名
POST /api/documents/upload
# 如果 title 已存在，返回 409 Conflict
# 响应体包含冲突信息，前端显示重名处理对话框
```

## 四、中栏多视图标签页

### 4.1 当前状态

中栏每次只显示一个内容，点击新卡片即替换，无状态保留。

### 4.2 目标状态

- **标签页管理**：每个打开的视图成为一个标签页
- **状态保留**：切换标签页时保留视图状态（如滚动位置、展开状态）
- **关闭标签页**：点击 × 关闭标签页
- **新标签页**：点击卡片时，在标签页栏创建新标签（或激活已有标签）
- **默认标签**：选中文档时的「文档原文」作为第一个标签

### 4.3 UI 设计

```
┌─────────────────────────────────────────────────────────────┐
│  [📄 发展心理学·第一章 ✕] [📝 自我意识训练题 ✕] [+ 新标签] │ ← 标签页栏
│  ─────────────────────────────────────────────────────────── │
│                                                             │
│  当前标签内容（DocumentReader / QuestionViewer / ...）      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.4 交互设计

| 操作 | 行为 |
|------|------|
| 点击任务卡片 | 如果该卡片已有标签页 → 激活该标签；否则 → 创建新标签页 |
| 点击标签页 | 切换到对应视图，保留状态 |
| 点击 ✕ | 关闭标签页（如果是唯一标签页，显示确认） |
| 点击「+ 新标签」 | 空白标签页，显示“请选择要查看的内容” |

### 4.5 状态管理

```javascript
// stores/useContentStore.js 扩展
{
  tabs: [

      contentType: 'document',
      contentData: { ... },
      title: '发展心理学·第一章',
      scrollPosition: 0,
      isPinned: false  // 是否固定（不可关闭）
    }
  ],
```

## 五、知识图谱可视化

### 5.1 当前状态

图谱以文本列表形式展示实体和关系，不直观。

### 5.2 目标状态

使用力导向图（Force-Directed Graph）可视化展示实体-关系网络。

### 5.3 技术选型

使用 **D3.js**（`d3-force`）或 **ECharts**（`graph` 系列）实现图谱渲染。

**推荐 ECharts**：更易集成 Vue，交互开箱即用（拖拽、缩放、悬停高亮）。

### 5.4 UI 设计

```
┌─────────────────────────────────────────────────────────────┐
│  🔍 知识图谱                                              │
│  [全部] [概念] [理论家] [理论] [方法]                      │ ← 类型筛选
│                                                             │
│  ┌─────────────────────────────────────────────────────────┐│
│  │                                                        ││
│  │         [皮亚杰]                                       ││
│  │        /       \                                       ││
│  │   [自我意识]---[形式运算]                              ││
│  │       |                                               ││
│  │   [自我概念]                                           ││
│  │                                                        ││
│  └─────────────────────────────────────────────────────────┘│
│                                                             │
│  图例：● 概念  ● 理论家  ● 理论  ● 方法                   │
└─────────────────────────────────────────────────────────────┘
```

### 5.5 交互设计

| 操作 | 行为 |
|------|------|
| 拖拽节点 | 调整节点位置（布局重置） |
| 悬停节点 | 高亮显示该节点及其连接关系 |
| 点击节点 | 右侧显示节点详情（名称、类型、描述、关联文档片段） |
| 滚轮缩放 | 缩放视图 |
| 类型筛选 | 显示/隐藏特定类型的实体 |
| 双击节点 | 跳转到中栏原文对应位置（如果有） |

### 5.6 数据转换

将实体-关系数据转换为 ECharts graph 格式：

```javascript
{
  nodes: entities.map(e => ({
    id: e.id,
    name: e.name,
    category: e.entity_type,  // concept/theorist/theory/method/fact
    symbolSize: 30,
    itemStyle: { color: categoryColors[e.entity_type] }
  })),
  links: relations.map(r => ({
    source: r.source_entity_id,
    target: r.target_entity_id,
    label: { show: true, formatter: r.relation_type }
  })),
  categories: [
    { name: 'concept', itemStyle: { color: '#409EFF' } },
    { name: 'theorist', itemStyle: { color: '#E6A23C' } },
    // ...
  ]
}
```
