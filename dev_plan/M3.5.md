## 二、交互设计

### 2.1 布局

```
┌─────────────────────────────────────────────────────────────┐
│  选择知识点                                                │
│  ┌───────────────────────┐   ┌───────────────────────────┐ │
│  │  📚 全部知识点         │   │  ✅ 已选 (3)              │ │
│  │  🔍 [搜索...]          │   │                           │ │
│  │  ─────────────────────  │   │  ──────────────────────── │ │
│  │  ▾ 青少年个性发展      │   │  ☑ 自我意识的基本特点    │ │
│  │    ▾ 自我意识          │   │  ☑ 自我概念              │ │
│  │      ☐ 基本特点        │   │  ☑ 形式运算阶段          │ │
│  │      ☐ 自我概念        │   │                           │ │
│  │      ☐ 自我评价        │   │  [清空全部]              │ │
│  │    ▸ 社会性发展        │   │                           │ │
│  │  ▸ 情绪发展            │   │                           │ │
│  └───────────────────────┘   └───────────────────────────┘ │
│                                                             │
│  已选：3 个知识点    [取消]           [确认创建]           │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 交互行为

| 操作 | 行为 |
|------|------|
| 点击左侧节点 | 选中（高亮） |
| 点击 `→` 按钮 | 将左侧选中节点移至右侧 |
| 点击 `←` 按钮 | 将右侧选中节点移回左侧 |
| 双击左侧节点 | 快速移至右侧 |
| 双击右侧节点 | 快速移回左侧 |
| 勾选父节点复选框 | 自动选中该节点下所有子节点 |
| 搜索框输入 | 过滤左侧列表，仅显示匹配项及父级路径 |
| 右侧点击 ✕ | 从已选列表中移除 |
| 「清空全部」 | 移除右侧所有已选 |
| 右侧拖拽 | 调整已选顺序（影响出题优先级） |

### 2.3 树节点状态

| 状态 | 显示 | 说明 |
|------|------|------|
| 未选中 | `☐` | 该节点及子节点均未被选择 |
| 部分选中 | `☒` | 部分子节点被选择 |
| 全选 | `☑` | 该节点及所有子节点均被选择 |
| 已选（右侧） | `✅` | 节点已在右侧列表中 |

```javascript
  children: [
    {
      id: 'node-1-1',
      label: '自我意识',
      type: 'folder',
      children: [
        { id: 'entity-1', label: '自我意识的基本特点', type: 'entity' },
        { id: 'entity-2', label: '自我概念', type: 'entity' }
      ]
    }
  ]
}
```
