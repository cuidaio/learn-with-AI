## 一、核心变更

### 1.1 当前问题

- 单次LLM调用处理全文档，大文档易超出上下文窗口
- 无并行，处理慢
- 无进度反馈，用户不知道提取到什么程度
- 无去重合并，同一实体在不同分块中被重复提取

### 1.2 目标

- 复用 M1 的分块逻辑，将文档切分为语义块
- 并行调用 LLM 提取实体，可控并发数
- 通过 Task 系统提供实时进度反馈
- 汇总后去重合并，消除冗余

### 1.3 配置参数

```python
# config.py
ENTITY_EXTRACTION_WORKERS: int = 5        # 并发数
ENTITY_EXTRACTION_CHUNK_SIZE: int = 1500  # 每块字符数（复用 M1 chunk_size）
ENTITY_EXTRACTION_OVERLAP: int = 200      # 重叠字符数（复用 M1 overlap）
ENTITY_EXTRACTION_SIMILARITY_THRESHOLD: float = 0.85  # 去重相似度阈值
```

## 二、处理流程

```
文档 cleaned_text
    ↓
【Phase 1】智能分块（复用 M1 chunking.py）
    ├── chunk_size = ENTITY_EXTRACTION_CHUNK_SIZE
    ├── overlap = ENTITY_EXTRACTION_OVERLAP
    └── 输出：List[Chunk]（包含 content, start_pos, end_pos）
    ↓
【Phase 2】并行 LLM 提取
    ├── asyncio.Semaphore(ENTITY_EXTRACTION_WORKERS)
    ├── 每个分块独立调用 LLM 提取实体
    ├── 每个分块完成后更新 Task.progress
    └── 单个分块失败不影响整体（asyncio.gather return_exceptions=True）
    ↓
【Phase 3】汇总去重
    ├── 按 (name_normalized, entity_type) 分组
    ├── embedding 相似度检测近似实体（阈值 ≥ 0.85）
    ├── 合并：保留首次出现 + 补充描述
    └── 记录每个实体的出现位置（chunk_index 列表）
    ↓
输出：List[Entity]
```

## 四、关键实现要点

### 4.1 分块（复用 M1）

不要重新实现分块逻辑。直接从 `app.core.chunking` 导入 `chunk_document`：

```python
from app.core.chunking import chunk_document

# 获取分块列表
chunks = chunk_document(cleaned_text, signals=[], is_structure_reliable=False)
```

### 4.2 并行控制

使用 `asyncio.Semaphore` 控制并发数：

```python
semaphore = asyncio.Semaphore(self.max_workers)

async def extract_one(chunk_content, chunk_index):
    async with semaphore:
        await self._update_progress(chunk_index, total_chunks)
        return await self._extract_chunk(chunk_content, chunk_index)

tasks = [extract_one(c.content, i) for i, c in enumerate(chunks)]
results = await asyncio.gather(*tasks, return_exceptions=True)
```

### 4.3 进度更新

通过 TaskManager 更新当前任务的进度：

```python
async def _update_progress(self, current: int, total: int):
    progress = int((current / total) * 100)
    await self.task_manager.update_progress(
        task_id=self.task_id,
        progress=progress,
        progress_text=f"正在提取第 {current+1}/{total} 个分块..."
    )
```

### 4.4 去重合并

- **实体名称**：归一化（去除空格、大小写统一）
- **分组**：`(name_normalized, entity_type)`
- **近似匹配**：用 embedding 相似度，阈值 0.85
- **合并**：保留首次出现 + 补充描述 + 记录所有 chunk_index
